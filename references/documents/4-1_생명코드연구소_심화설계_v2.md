1. **5개 Stage를 하나의 큰 사건을 해결하는 5개의 Mission으로 연결**

# 1. 기존 설계 진단

## 강점
- 성취기준의 `관찰·조사·설명·자료 제작`을 실제 행동으로 전환했다.
- 초점 다이얼, 촬영, 주석, 추적, A/B 비교, 자료 선별, 3D 조립 등 태블릿 고유 상호작용이 충분하다.
- 실제 생물 관찰 자료와 게임 캐릭터를 분리해 과학적 왜곡 가능성을 줄였다.
- 세균 전체를 나쁜 존재로 표현하지 않고 상황과 근거를 보게 한다.

## 보완이 필요한 부분
- 화면별 활동은 좋지만 하나의 사건을 해결한다는 연결감이 약할 수 있다.
- `균류 코드`, `세균 코드`가 단순 아이콘 수집이 되면 의미 없는 열쇠가 될 위험이 있다.
- Mission 완료 결과가 연구소 세계 변화로 충분히 남아야 한다.
- Stage 5 완료 후 자동으로 엔딩을 보여주지 말고 학생이 최종 행동을 해야 한다.

## 학습지형으로 보일 수 있는 부분
- Page 06 세균 자료 선별
- Page 08 생활 영향 분석
- Page 10 연구 카드 정리

이 화면들은 카드 선택 자체가 아니라

> 자료 열기 → 확대 → 비교 → 근거 연결 → 오류 확인 → 원본 재검토 → 수정

이 중심이 되게 한다.

# 2. 단원 메인 퀘스트

## 사건 — BIO CORE 데이터 교란

Science World의 생명 연구 시설 **생명 코드 연구소**는 균류·원생생물·세균에 관한 관찰 정보와 우리 생활의 생명과학 활용 데이터를 관리한다.

어느 날 중앙 **BIO CORE**에서 데이터 연결 오류가 발생한다.

- 균류의 발견 환경과 관찰 특징이 분리됨
- 물 표본 관찰 데이터가 끊김
- 세균 관찰 자료와 추측 자료가 뒤섞임
- 생활 속 영향 사례가 “무조건 도움 / 무조건 해로움”으로 잘못 분류됨
- 생명과학 활용 장치가 잘못된 데이터를 받아 멈춤

BIO CORE를 다시 가동하려면 비밀번호가 아니라 **과학적으로 검증된 다섯 개의 Evidence**가 필요하다.

# 4. 최종 목표와 Evidence

학생은 다음 5개 Evidence를 복구한다.

1. **균류 관찰 패킷**  
   발견 환경 + 현미경 촬영본 + 학생 주석

2. **원생생물 비교 기록**  
   해캄·짚신벌레 촬영본 + 비교 근거

3. **세균 증거 프로필**  
   학생이 선별한 확대 자료·장소 자료 + 설명

4. **생활 영향 사건 보고서**  
   사건·단서·영향·근거

5. **BIO 솔루션 설계도**  
   생활 문제 + 활용 사례 + 3D 설계 + RUN 결과

## PAGE 01 — MISSION 01-A 「균류 표본실」

### 화면 목적
균류 표본이 발견된 환경과 변화 양상을 조사하여 현미경 관찰 전에 필요한 Evidence를 확보한다.

### 학생에게 보이는 상황
연구소 첫 구역이 반쯤 꺼져 있다. 모아 연구원이 말한다.

> “균류의 발견 장소와 관찰 기록이 따로 떨어졌어. 표본 주변에서 직접 증거를 다시 모아 줘.”

### 학생이 해야 하는 행동
1. 버섯/곰팡이 안전 표본 선택
2. BIO-LENS로 표본 주변 스캔
3. 발견 위치·빛·습도 등 현재 표본 관련 정보 확인
4. 시간 슬라이더로 변화 전후 비교
5. 관찰 근거 2종 이상 저장

### 태블릿 조작
- 제한 3D 회전 또는 2.5D 표본 회전
- BIO-LENS drag
- hotspot tap
- timeline scrub
- long press 관찰 핀

### 조작에 따른 화면 반응
- 스캔 영역에 따라 환경 정보가 달라진다.
- timeline을 움직이면 검수된 표본 상태가 시간에 따라 바뀐다.
- 실제로 확인한 항목만 Research Kit에 들어간다.

### 과학 개념
- 균류의 관찰 특징
- 표본이 발견되는 환경
- 관찰과 Evidence 기록

### 실패 상황
한 종류의 정보만 모아 설명이 불완전한 경우.

### 재시도
다른 hotspot을 직접 탐색해 즉시 Evidence 보완.

### 성공 조건
서로 다른 유형의 유효 Evidence 2개 이상.

### 다음 화면 연결

3. 곰팡이 밀폐 표본
4. 비교 표본

```text
생활 영향 사건 보고서 → 확인 ✓
BIO 솔루션 설계도     → 확인 ✓
```

각 Evidence 전달 때 학생의 실제 수행 기록을 2~3초 펼쳐 보여준다.

- 균류: 학생 촬영 사진 + 주석
- 원생생물: A/B 비교 기록
- 세균: 학생이 고른 근거 3개
- 생활 영향: 사건 보고서 핵심
- BIO 솔루션: 설계 thumbnail + RUN 결과

Final Report는 새 시험이 아니라 **탐구 회고 장치**이다.

# 13. Final Mission — BIO CORE를 직접 복구하라

## 목표
단순 `[완료하기]` 버튼 금지.

## 단계 1 — Evidence 연결

BIO CORE 주변에 5개 의미 포트:

```text
관찰
비교
자료
영향
활용
```

학생이 Research Kit에서 자신의 Evidence를 각 포트로 직접 연결한다.

단순 맞추기 게임이 되지 않도록 각 Evidence에는 **학생이 직접 만든 실제 결과 thumbnail**이 표시된다.

## 단계 2 — 연결 검증
연결이 맞으면 CORE 내부 데이터 라인이 이어진다.

연결이 적절하지 않으면:
- 빨간 X 없음
- 데이터 선이 중간에서 멈춤
- Evidence 원본을 다시 열어 확인 가능

## 단계 3 — 최종 가동
모든 연결이 완성되면 중앙 **BIO CORE 가동 레버** 활성화.

학생이 레버를 **아래 방향으로 길게 Swipe**한다.

그 순간:

```text
BIO CODE SYNC
5 / 5

LAB RESTORATION
100%
```

최종 행동의 주체가 학생이 되도록 한다.

# 부록 B. 절대 유지 규칙

1. 4학년 성취기준 범위 유지
2. 전문 생명공학 원리 선행 학습 금지
3. 실제 생물 관찰 자료의 과학적 정확성 우선
4. 세균·균류 전체를 좋음/나쁨으로 일반화 금지
5. 부엉이·로봇 캐릭터 사용 금지
6. 캐릭터는 반드시 기능 보유
7. 페이지당 핵심 에셋 약 10개 이하
8. UI는 CSS/DOM/SVG
9. 태블릿 가로형 우선
10. 전자칠판 뒷자리 가독성 확보
11. OX/객관식만으로 Mission 완료 금지
12. 동일 Drag 로직 반복 금지
13. 실패 즉시 정답 공개 금지
14. Evidence 없는 주장 통과 금지
15. Mission 완료가 World Change로 남아야 함
16. Mission 5 후 자동 엔딩 금지
17. Final Report 후 학생이 직접 Final Mission 수행
18. Final Movie 후 인증서 해금
19. Bonus Quest는 선택형
20. Science World 핵심 메타는 **QUEST / EVIDENCE / WORLD CHANGE / FINAL REPORT**
