## 1. 제품 한 줄 정의

학생이 균류·원생생물·세균의 이름을 외우거나 객관식 문제를 반복하는 대신, **관찰 장비 조작 → 표본 탐색 → 증거 촬영·표시 → 자료 선별 → 생활 사건 조사 → 근거 기반 판단 → 생명과학 활용 설계 → 연구 자료 제작**을 수행하며 5개의 생명 코드를 복구하는 초등 4학년 수행형 과학 게임.

## 2. 문제 정의

「다양한 생물과 우리 생활」은 관찰, 조사, 설명, 자료 제작이 핵심이다. 따라서 설명 슬라이드 읽기, OX/객관식 반복, 이름만 보고 분류하기, 같은 드래그 앤 드롭 반복, 영상 시청 후 정답 선택, 단순 캐릭터 꾸미기만으로는 태블릿을 사용할 이유가 약하다.

본 제품은 태블릿을 **디지털 현미경·관찰 노트·증거 분석판·사건 조사 장비·생명과학 설계 작업대**로 사용한다.

### 태블릿 고유 가치
1. 현미경의 **배율·밝기·초점**을 직접 조절한다.
2. 관찰 화면의 위치를 움직이고 필요한 부분을 **촬영**한다.
3. 촬영한 화면 위에 직접 **표시·주석**을 남긴다.
4. 움직이는 원생생물을 시야 안에서 **추적**한다.
5. 서로 다른 관찰 자료를 **나란히 비교**한다.
6. 세균 관련 자료 중 설명에 필요한 증거를 **선별**한다.
7. 생활 사건 현장을 **스캔하고 단서를 수집**한다.
8. `생물 → 특징/작용 → 생활 영향`을 **근거와 함께 연결**한다.
9. 생명과학 활용 아이디어를 **3D 연구 장치로 조립하고 실행**한다.
10. 앞 Stage에서 모은 기록을 재사용해 **최종 연구 카드**를 만든다.

## 3. 교육과정 근거

### [4과12-01]
**균류·원생생물·세균을 관찰하여 특징과 사는 곳을 설명할 수 있다.**

게임 반영:
- Stage 1: 균류 표본·사는 환경 조사, 실체현미경 조작, 관찰 증거 확보
- Stage 2: 해캄·짚신벌레 표본 채집 시뮬레이션, 현미경 탐색·추적·촬영, 비교
- Stage 3: 세균 확대 자료·영상·발견 장소 기록을 선별하여 특징과 사는 곳 프로필 작성

### [4과12-02]
**균류·원생생물·세균이 우리 생활에 미치는 영향을 조사하여 발표할 수 있다.**

게임 반영:
- Stage 4: 생활 사건 현장 조사
- 생물의 종류 자체를 좋음/나쁨으로 분류하지 않고 **상황 속 영향**을 판단
- 조사한 단서와 관찰 기록을 근거로 영향 설명
- 사건 보고서에 근거가 포함되어야 완료

### [4과12-03]
**우리 생활에 생명과학이 이용되는 사례를 소개하는 자료를 만들어 공유할 수 있다.**

게임 반영:
- Stage 5: 검수된 생명과학 활용 사례 자료 조사
- `생활 문제 → 관련 생물/생명 현상 → 이용하는 특징/작용 → 활용 결과` 구조로 설계
- BIO 연구 카드 제작, PNG 저장/공유

## 4. 첨부자료 벤치마킹 원칙

첨부 자료는 **기능과 학습 효과를 높이기 위한 참고자료**로만 사용한다. 화면, 캐릭터, 문항, 도안, 게임 규칙, 슬라이드 레이아웃은 그대로 복제하지 않는다.

### 직접 참고할 학습 요소
1. **버섯·곰팡이 관찰**
   - 균류의 특징과 사는 곳
   - 실처럼 가늘고 긴 균사 관찰
   - 맨눈/돋보기/실체현미경으로 관찰 범위를 달리하는 경험
   - 낮은 배율부터 시작, 밝기·초점 조절 등 현미경 사용 절차
   - 곰팡이 표본을 맨손으로 만지거나 코에 가까이 대지 않는 안전 원칙
2. **원생생물 관찰**
   - 해캄과 짚신벌레 관찰
   - 물 한 방울 속 생물을 찾아보고 비교하는 경험
3. **세균**
   - 사진·영상·확대 자료로 특징과 사는 곳을 알아보는 방식
4. **우리 생활에 미치는 영향**
   - 균류·원생생물·세균이 생활에 도움을 주거나 문제를 일으킬 수 있다는 사례
   - 발효, 분해, 음식의 변화, 질병 등은 검수된 사례만 선별
5. **생명과학 이용**
   - 미생물을 활용한 생활·환경·산업 사례는 아이디어 소재로 참고
   - 전문 원리·세부 종명 암기는 필수 학습으로 사용하지 않음
6. **캐릭터 만들기 활동**
   - “어떤 생물의 어떤 특징을 어떻게 표현할 것인가”라는 사고 과정만 참고
   - 본 게임에서는 과학적 근거가 포함된 BIO 연구 카드 제작으로 변환

### 사용하지 않을 방식
- PPT 화면 복제
- 외부 영상 자체를 필수 콘텐츠로 탑재
- OX/빈칸/초성 문제 반복
- 캐릭터 모양을 보고 생물 이름만 맞히기
- 가위바위보 규칙 자체 복제
- 기존 자료의 점수/보상/게임판 복제
- 5학년·6학년 수준의 전문 생명공학 원리 선행 학습

## 5. 대상 사용자와 난이도

### 학생
- 초등학교 4학년
- 짧고 명확한 문장
- 조작법은 직관적이어야 하지만 사고 수준은 낮추지 않음

### 교사
- 단원 도입, 차시 연결, 정리, 보충·심화에 활용 가능
- 학생의 관찰·증거·재시도 기록을 로컬에서 확인 가능
- 실제 실험·현미경 관찰을 대체한다고 주장하지 않음

### 4학년 난이도 원칙

쉬워야 하는 것:
- 버튼 의미
- 드래그/회전/줌 조작
- 문장 길이
- 힌트 접근

낮추지 않을 것:
- 관찰 증거 찾기
- 두 자료 비교
- 필요한 자료와 불필요한 자료 구분
- 원인과 영향 연결
- 근거를 붙여 설명하기
- 실패 결과를 보고 수정하기
- 자료를 재구성하여 소개하기

### 금지
- 한 번 탭하면 자동 완료
- OX/객관식만으로 Stage 완료
- 정답 위치로만 드래그
- 동일한 카드 분류 활동 반복
- “세균은 나쁘다”, “곰팡이는 나쁘다” 같은 일반화
- 실패 즉시 정답 공개
- 과학적 관찰 자료를 귀여운 3D 캐릭터로 대체
- 유아용 스티커북 분위기

## 6. 세계관

Science World 생명 영역의 연구 시설 **생명 코드 연구소**에서 중앙 BIO CORE의 연구 데이터가 손상되었다.

1. **균류 코드**

4. **생활 영향 코드**

## 7. 전체 학습 흐름

**연구소 진입 → 균류 환경 조사 → 현미경 조작·증거 촬영 → 물 표본 채집 → 원생생물 추적·비교 → 세균 데이터 선별 → 생활 사건 조사 → 영향 판단·근거 설명 → 생명과학 활용 설계 → 작동 결과 확인·수정 → 연구 카드 제작 → BIO CORE 복구**

## 9. Stage 1 — 균류 코드

### Page 02 — 균류 표본실
목표: 버섯과 곰팡이 표본이 발견되는 환경과 관찰 특징을 조사한다.

행동:
1. 표본 선택
2. 주변 환경 스캔
3. 시간 슬라이더로 변화 비교
4. 필요한 관찰 증거 2개 이상 저장

주의:
- 모든 균류가 동일한 환경에서만 산다고 일반화하지 않는다.
- 현재 검수 표본에서 확인한 사실을 우선한다.

### Page 03 — 현미경 분석실
행동:
1. 표본을 재물대에 놓기
2. 낮은 배율 선택
3. 밝기 조절
4. 초점 다이얼 조절
5. 표본 위치 이동
6. 관찰 사진 촬영
7. 사진 위 특징 표시
8. 버섯·곰팡이의 공통 관찰 증거 선택

완료:
- 유효한 관찰 사진 2장 이상
- 특징 표시 2곳 이상
- 관찰 증거를 근거로 한 설명 1개

보상: `CODE-01 FUNGI`

## 10. Stage 2 — 원생생물 코드

### Page 04 — 한 방울 채집실
행동:
- 채집 지점 선택
- 스포이드 압축 → 물에 넣기 → 놓기
- 받침 유리에 적정량 옮기기
- 표본 상태 확인

디지털 가치:
- 실제 표본 제작을 대신하지 않고 절차를 안전하게 반복 연습한다.

### Page 05 — 원생생물 추적실
목표: 해캄과 짚신벌레를 탐색·추적·촬영하고 서로 다른 특징을 근거로 비교한다.

행동:
- 현미경 시야 이동
- 해캄 관찰 지점 촬영
- 움직이는 짚신벌레 추적·촬영
- 촬영본 나란히 비교
- 생김새·움직임·사는 곳 관련 증거 연결

완료:
- 해캄 1개 유효 기록
- 짚신벌레 1개 유효 기록
- 비교 증거 3개 이상

보상: `CODE-02 PROTISTS`

## 11. Stage 3 — 세균 코드

### Page 06 — 세균 데이터실
목표: 제공된 확대 자료·영상 프레임·발견 장소 기록에서 필요한 근거를 골라 세균의 특징과 사는 곳을 설명한다.

자료 유형:
- 확대 관찰 이미지
- 짧은 관찰 영상 프레임
- 발견 장소 기록
- 연구 메모
- 관련 없는 자료
- 근거 없는 추측 메모

완료:
- 근거 자료 3개 이상
- 특징 1개 이상
- 사는 곳 관련 설명 1개 이상

보상: `CODE-03 BACTERIA`

## 12. Stage 4 — 생활 영향 코드

### Page 07 — 생활 사건실
사건 예시:
- 발효 음식이 만들어지는 사례
- 오래 둔 음식의 모습이 변한 사례
- 죽은 생물이나 낙엽이 분해되는 사례
- 생물이 사람·동물·식물의 건강에 문제를 일으키는 사례
- 물 환경에서 생물의 수가 크게 변해 문제가 생기는 검수 사례

※ 실제 탑재 사건은 `impact-cases.json`에서 교과 검수 후 확정한다.

행동:
- 현장 자유 스캔
- 시간/환경/관찰 상태 확인
- 관련 자료 열기
- 단서 3개 이상 저장

### Page 08 — 영향 분석실
논리: `사건 → 관련 생물/자료 → 생활에 미친 영향 → 근거`

중요:
- 생물군 전체를 이로운/해로운 것으로 고정 분류하지 않는다.
