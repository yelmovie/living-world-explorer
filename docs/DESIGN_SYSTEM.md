# 생명 코드 연구소 디자인 시스템

2026-10-21 · 가로 태블릿 MVP · 그림 중심의 탐험과 명확한 조작

## 시각 방향

숲의 세이지색, 연구 조끼의 진한 초록, 현장 기록장의 크림색, 복구등의 따뜻한 금색을 사용한다. 탐험 세계와 캐릭터는 생성 이미지가 표현하고, Phaser는 실제 이동·관찰·조립을 담당한다. 글자와 버튼은 DOM으로 표시한다. 장식용 풍경을 CSS 도형으로 재현하지 않는다.

지도는 2.5D 픽셀 RPG, 시설 내부는 2D 탐구 장면이다. 둘 다 크림색 현장 기록장과 진한 초록 테두리를 공통 재질로 사용한다. 투명도를 쓴 패널에도 글자는 불투명하게 표시하며, `backdrop-filter`는 사용하지 않는다.

## 글자와 조작

제목·버튼·본문은 로컬 나눔스퀘어 네오(NanumSquareNeo) WOFF2를 사용한다. 보통 글씨는 400, 굵은 글씨는 700이며 폰트 외부 요청은 없다. 라이선스는 `public/assets/fonts/NanumSquareNeo-OFL.txt`, 공식 배포 출처와 파일별 SHA-256은 `public/assets/fonts/NanumSquareNeo-SOURCE.json`에 동봉한다.

- 본문 기본 20px, 버튼 22px, 활동의 핵심 질문 30~32px, 큰 제목 44px 이상이다.
- 1500×850 이상은 본문 24px, 버튼 26px, 핵심 질문 38px로 확대한다.
- 버튼은 기본 48px 이상이고 주요 행동은 56px 이상이다. 코너 아이콘은 52px, 전자칠판에서는 60px이다.
- 버튼에 hover / active / disabled / focus 네 상태가 있다. 누르면 본체가 3px 내려가고 하단 엣지가 줄어든다.
- 한글은 어절 단위로 줄바꿈한다. 짧은 제목만 균형 줄바꿈을 사용한다. 긴 설명을 줄이기 위해 작은 글씨로 축소하지 않는다.
- 비활성 행동의 이유는 화면 코드가 짧게 설명해야 한다. CSS만으로는 완료 조건이나 이유를 판단하지 않는다.

## 화면 틀

`iscream-settings/references/screen-frame.md`의 2026-10-20 공통 틀을 적용한다.

- 홈·이전은 좌상단, 소리·설정은 우상단에 그림 위로 떠 있다. 첫 화면의 홈·이전은 숨긴다.
- 상단 제목 띠, 복구 숫자 HUD, 하단 안내 띠는 두지 않는다. 로고 브랜드 띠와 저장 상태 줄은 학생 화면에서 숨긴다.
- 핵심 질문은 위 가운데의 가장 큰 글자다. 지도는 화면 끝까지 이어지며 이동 카메라가 세계를 따라간다.
- 주요 행동은 오른쪽 아래, 이전/지도로는 왼쪽 아래에 둔다. 버튼 행에 별도 바탕이나 경계선을 넣지 않는다.
- 안내 캐릭터는 누르면 말풍선을 연다. `.mentor-card.expanded` 또는 `[data-open="true"]`에서만 `.mentor-speech`를 표시한다.

## 설정·이야기·보상

설정은 `.settings-dialog` 안에서 제목과 `.settings-footer`가 고정되고 `.settings-scroll`만 스크롤된다. 접힘은 native `details/summary`로 구현한다. 설정 항목 순서와 저장·해금 규칙은 `iscream-settings`를 따른다.

보상은 학생의 증거 기록이 만들어진 뒤에만 표시한다. 크림색 보상 창, 금색의 발견 표식, 초록색의 세계 복구 문구를 사용하며 계속 흔들리는 장식이나 섬광을 넣지 않는다. 보상 중복 지급 방지와 해금 판정은 상태 로직의 책임이다.

## 반응형과 접근성

우선 검증 크기는 1280×720, 1280×800, 1024×768, 1366×768, 1920×1080이다. 작은 가로 화면에서는 여백과 장식 크기를 먼저 줄이고 주요 글자와 터치 크기는 유지한다. 큰 글씨 모드도 현재 조작을 한 화면에 유지하고, 긴 조사 자료는 별도 창에서 읽는다.

`prefers-reduced-motion` 및 `.reduced`에서 CSS 반복 애니메이션과 전환을 끈다. Phaser의 걷기·파티클·카메라 연출은 렌더러가 같은 설정을 적용해야 한다.

짧은 가로 화면에서도 발견 단계 표시와 기록 버튼을 함께 유지한다. 탐구 패널의 윗부분은 항상 보이며, 선택 직후 결과나 다시 시도할 방법이 들어갈 때 다음 안내 문장을 잠시 대신한다. 기록 가능한 상태는 문구와 테두리로 구분하고, 새로 준비됐을 때만 짧게 강조한다. 다음 조작을 시작하면 결과 대신 안내 문장으로 돌아온다.

이 문서는 디자인 규격이다. 브라우저의 실제 크기·잘림·겹침·입력 검증 결과를 대신하지 않는다. 최종 검증 보고서에서 측정한 화면만 통과로 표시한다.

## 스테이지 반응형 보강 · 2026-11-08

카드의 그림·이름·선택/완료 표시는 서로 다른 공간을 사용한다. 연결 기록은 그림 위에 글자를 얹지 않고 제목, 연결한 자료 수, 썸네일을 순서대로 보여 준다. 긴 선택지는 좁은 도구 패널에서 한 열로 전환한다. 단계 번호와 도구 이름, 슬라이더의 현재값과 조절 버튼도 각각 공간을 확보한다.

질문은 보조 미션 문구보다 우선한다. 탐구 화면은 가용 화면 높이를 모두 사용하며 실험, 현재 조작, 기록 버튼을 한 화면에 배치한다. 가로 화면은 실험과 조작을 나란히, 세로 화면은 위아래로 배치한다. 현재 단계에 필요한 도구만 보여 주고, 긴 보충 자료와 도움말은 버튼으로 연다. 연결 보드의 모든 카드도 스크롤 없이 배치한다. 이전의 도구·연결 보드 내부 스크롤 허용 규칙보다 이 계약을 우선한다.

자동재생과 속도 선택(0.5·1·1.5·2배)은 조작 패널에 함께 둔다. 속도를 재생 중에도 바꿀 수 있으며 발효·설계 가동에도 같은 속도를 적용한다. 채집 장소, 정답, 주장·근거, 관찰 특징은 사용자가 결정한다. 자동재생은 준비·관찰만 진행하고 발견 제출과 다음 스테이지 이동은 사용자가 누른다. 도움말·설정 열기, 화면 이탈 시 관찰 재생을 멈추고 원래 기록을 복구한다.

채집은 장소→한 방울→유리판, 설계는 재료→작용→결과를 같은 순서로 보여 준다. 전후 관찰은 사진과 시간 선택 영역을 분리하고, 발효에서는 시계와 결과 음식의 자리를 구분한다. 장면의 효과는 실제 관찰·자료 확인·실행 상태와 연결한다.

## 2026-10-24 적용 보강

기존 색상과 글꼴은 유지했다. 지도는 건물과 보행 경로를 보존한 v3 생성 그림을 사용하며 Phaser 로딩 전에도 같은 풍경을 표시한다. 자료·채집·복구 그림 10장의 원본과 프롬프트는 `ART_GENERATION_20261024.md`에 기록했다.

활동 질문과 작은 제목에는 불투명한 크림색 바탕을 두어 시설 그림과의 대비를 확보한다. 선택된 발견 버튼은 hover에서도 짙은 초록색을 유지한다. 교사용 시연은 위 가운데 종료 버튼으로 상태를 표시하며 학생 기록으로 돌아갈 수 있다.

관찰 도감의 썸네일은 저장된 초점·밝기·확대·이동·표시와 시간 고정 값을 복원한다. 작은 그림을 누르면 실제 관찰 사진을 크게 볼 수 있다. PNG 소개 카드는 학생이 선택한 사례·생물의 작용·소개 문장과 관련 그림을 내보낸다.

## 중앙 연구소 · BIO 코어

온실 안의 오래된 관찰 장치를 본떠 나무 받침·황동 고정대·유리 챔버·결정 군집을 Three.js에서 렌더링한다. 온실 그림의 창 쪽을 재사용해, 결정에 같은 공간이 굴절되어 보이게 한다. 화면 크기에 맞춰 고정 카메라가 모형과 포트 번호를 한 화면에 담는다. 화면 오른쪽 기록 버튼의 번호와 코어 램프의 번호를 맞춘다. 버튼은 연구소 이름, 번호, 연결 상태를 함께 보여 준다. 다섯 기록을 연결하면 가동 버튼이 열린다. 학생은 카메라를 돌리거나 작은 램프를 겨냥할 필요가 없다.

포트를 연결하면 해당 3D 램프와 배선이 켜진다. 가동 중에는 결정이 천천히 떠올라 돌고 결정 내부의 결이 빛난다. 동작 줄이기 설정에서는 점등으로 상태를 알려 준다. Three.js는 코어를 열 때 불러오고 화면을 나가면 렌더러를 해제한다. WebGL이 없거나 컨텍스트가 끊기면 기존 WebP로 전환한다. 화면 그림이 없어도 기록 연결은 가능하다. 좁은 가로 화면에서는 버튼을 2열로 배치하고 마지막 긴 제목은 한 행을 사용한다.

## 납품 반응형 보강 · 2026-11-11

높이 480px 이하 가로 화면은 연결 활동의 조작 노트를 오른쪽에 배치한다. 현재 활동 질문과 모든 카드의 이름을 우선하고, 사건의 전체 질문은 증거판에서 읽는다. 세로 휴대폰은 사건 증거판 버튼을 하단 독립 행에 둔다. 긴 보고서와 코어 기록은 세로 스크롤로 끝까지 접근할 수 있어야 한다. 확인된 짧은 가로 화면의 연결 활동은 모든 자료와 분류 칸을 한 화면에 담는다.

시작 화면과 다음 조작 안내의 반복 움직임은 2~3회 후 멈추며, 조작 가능한 위치는 정적인 테두리로 유지한다. 지도 보기 도구, 토토 힌트, 걷기 버튼은 서로 별도의 터치 영역을 사용한다. 탐정 증거판에서 ‘연결됨’은 배치 상태를 나타내며, 설명 확인을 통과한 뒤 완료 상태가 된다. 배치를 바꾸면 설명을 다시 확인한다.
