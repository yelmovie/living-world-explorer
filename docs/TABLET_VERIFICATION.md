# 가로 태블릿 탐험 검증 결과

2026-10-18 · 현재 구현 기준: [탐험 설계 v1.2](TABLET_EXPLORATION.md)

## 구현 상태

2D Phaser 지도와 5개 스테이지, 총 15개 화면을 연결한 프로토타입이다. 관찰·촬영·특징 표시, 물 채집과 두 시점 비교, 주장과 원문 근거 연결, 생활 영향의 시간 비교, 예상 후 설계 실행, 기록 보고와 BIO CORE 복구를 수행할 수 있다. 완료 기록에서 다음 장소와 복구 보상이 파생되며 관리자 예시는 학생 진도와 분리된다.

## 자동 검증

| 검사 | 결과 | 범위 |
|---|---|---|
| `npm test` | 20개 통과 | 다섯 미션 판정, 무효 근거 거부, 과거 설계 성공/중단 실행 거부, 손상 기록 복원, 해금 경계 |
| `npm run build` | 통과 | TypeScript 검사 및 Vite 프로덕션 번들 생성 |
| `npm run test:flow` | 통과 | 새 연구 → M1~M5 → 실제 기록 보고 → 코어 연결/가동 → 결과 편집 → PNG 다운로드 → 새로고침 복원 |
| `npm run test:browser` | 45개 화면 검사 통과 | 1280×800·1024×768·1280×720에서 15개 경로, 가로 넘침·주요 행동 버튼 잘림·오류 대체 화면·요청 실패·런타임 오류 검사 |
| 관리자 예시 분리 | 통과 | 전체 해금 예시 확인 후 해제 및 새로고침 시 학생 복구 진도 0/5 유지 |

브라우저 검증은 Windows의 로컬 Chromium과 터치 가능한 가상 화면을 사용했다. 완주 과정에서 틀린 예상을 선택해도 실행 결과를 관찰하고 타당하게 설명하면 M5를 완료하는 경로를 확인했다. PNG는 `생명코드-소개카드.png`로 내려받았고 결과 제목과 문장의 복원도 확인했다.

Phaser는 캔버스가 DOM에 붙은 뒤 장면을 그리므로, 테스트가 캔버스 존재만 확인한 직후 빈 배경을 촬영하던 문제를 보완했다. 보이는 Phaser 캔버스의 실제 그리기를 기다리며, 전후 비교 모드에서 의도적으로 숨긴 실시간 타임라인은 제외한다. 지도·현미경·조립·결과 화면은 스크린샷도 직접 확인했다.

## 검증 증거와 재실행

- `tests/domain.test.ts`: 학습 판정과 저장 상태의 단위 검증.
- `tests/browser-check.mjs`: 45개 화면과 관리자 예시 분리.
- `tests/full-flow.mjs`: 학생 완주·PNG 저장·복원.
- `tests/browser.mjs`: 브라우저 경로 선택과 Phaser 렌더 대기.
- 로컬 `.tmp/browser-audit.json`, `.tmp/full-flow.json`, `.tmp/screens/`, `.tmp/result-card.png`: 실행 결과와 화면 증거. 캐시·빌드와 함께 Git에서 제외한다.

실행 환경변수와 서버 명령은 [README](../README.md)의 브라우저 검증 절을 따른다. 별도 브라우저 설치가 필요한 환경에서는 Playwright 브라우저를 프로젝트의 D: 캐시에 설치한다.

## 남은 검증과 자료

- 보강한 완주 검증의 첫 실행에서 첫 지도 렌더 대기 30초 타임아웃이 한 번 발생했다. 같은 코드 재실행에서는 지도 렌더를 통과했다. 간헐적인 초기화 지연의 원인은 확정하지 않았으며 저사양·반복 실행 확인이 남아 있다.
- 실제 Android Chrome·iPad Safari의 손가락 조작, 저장 공간 제한, 메모리와 프레임 성능, PNG 저장과 인증서 인쇄는 미검증이다.
- 큰 글씨·보조 입력·키보드 전체 경로 및 느린 네트워크를 이 45개 기본 화면 검사만으로 통과 처리하지 않는다.
- 관찰 그림은 설명용 모형이다. 실제 현미경 사진, 동일 개체/표본의 시간 자료, 자료 권한과 교과 내용은 수업 배포 전에 검수해야 한다.
- 학생 파일럿과 35~45분 수업 시간, 흥미·학습효과는 아직 검증하지 않았다.
- 도입·엔딩 영상은 [기존 제작 캔버스](https://chatgpt.com/space/page_b460050fb99081919a7ca655d9b2e6c5)에 프롬프트만 정리되어 있다. 영상 제작과 재생 연결은 미완료이며 현재 학습 흐름은 영상 없이 동작한다.

판정: 개발용 프로토타입의 기능 검증 완료. 학생용 공개는 과학 자료·교과 검수와 실기기 확인 후 판단한다.
