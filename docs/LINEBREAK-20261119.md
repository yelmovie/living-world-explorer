## 남은 것(오탐으로 판정)

- 126px 좁은 버튼 두 낱말 「다시 / 관찰하기」「표시 / 되돌리기」「움직임 / 다시 보기」「작용 다시 / 고르기」「소개할 사례 / 바꾸기」: 한 줄에 안 들어가 두 줄이 되고, balance로 이미 고르다. 도구의 「끝줄 4자 이하」 규칙에만 걸림.
- M3-4 문장 완성 「세균은 짚신벌레보다 훨씬 [작고][크고] … 있으며, / [흙·물·손처럼…][물속에만] 살아요.」: 선택 버튼이 줄에 섞여 있어 도구가 버튼을 빼고 잼. 화면에서는 두 줄이 고르다.
- M5-1 제목 「발효기로 요구르트를 / 만들어요」(43%): 이미 balance 결과.
- 결과 카드 「소개할 사례: 요구르트」 첫 줄: 이름표 줄로 일부러 나눈 구조.
- 측정하지 못한 것: 「내 발견 도감」 버튼을 지도에서 찾지 못해 도감 창은 이번 측정에서 빠졌다. 개념 영상 자막(영상 위 글)·캔버스 글은 범위 밖.
