## 3차 수정(2026-11-20): 효과음 크기, 개념 영상 소리, 첫 입력 전 재생

- 설정 「소리」에 **효과음 크기**(0~100%, 5% 단위, 기본 100%)를 더했다. 저장 키 `settings.effectVolume`. 효과음 버스·전투음 버스(`EFFECT_GAIN .5`)와 발자국(`STEP_LEVEL`)에 곱한다. 100%에서 버스 0.5·0.5, 발자국 0.17·0.26으로 3차 전과 같다. 배경 음악은 따로(`bgmVolume`). 효과음을 끄면 슬라이더가 잠긴다.
- 설정 「소리」 순서: 효과음 | 효과음 크기, 배경 음악 | 배경 음악 크기, 캐릭터 목소리(스위치 옆에 자기 슬라이더). 슬라이더 터치 높이 16→48px.
- 저장 호환: `effectVolume`이 없으면 100. 목소리(`voice`)가 없으면 그때의 효과음 스위치(`sound`)를 따른다(1차부터 그대로). 새 학생 기본값은 전부 켜짐.
- 개념 영상 5개는 효과음(페이지 넘김·찰칵·차임)만 담고 따로 읽는 자막 음성이 없다(ffprobe 오디오 트랙 있음, `films/concept-M*/index.html`의 `<audio>`는 효과음뿐). 그래서 겹침 줄임은 해당 없음. 영상 소리는 이제 효과음 스위치만 따른다(전에는 효과음이나 목소리 중 하나만 켜져도 소리가 났다).
- 첫 입력 전 재생: 새 학생·새로고침·지도 기록 새로고침 모두 입력 없이 4초 동안 재생 시도 0번, AudioContext 0개, NotAllowedError 없음(해당 없음). 첫 키 뒤 메인 테마 재생.
