# 가로 태블릿 탐험 설계와 구현

2026-10-18 · v1.2. 이번 사용자의 2D Phaser 요청을 기준으로, 이전 v1.1의 지도 2.5D·5장/코어 실제 3D 지정을 대체한다. 5개 스테이지, 학습 활동 10개, 전체 15개 route와 기존 학습 판정·저장 구조는 유지한다.

## 초기 대화 반영

[공유된 초기 설계 대화](https://chatgpt.com/share/6accea16-e770-83ee-adad-82c972670d4b)를 브라우저에서 직접 열어 읽고 화면을 확인했다. 대화의 심화설계 v2에 있던 QUEST → EVIDENCE → WORLD CHANGE → FINAL REPORT → FINAL MISSION 흐름을 이어간다. 같은 파일명의 로컬 심화 설계서도 대조했다.

핵심 사건은 생명 코드 연구소의 관찰 기록 연결이 끊어진 것이다. 학생은 다섯 장소에서 조사하고, 실제 자신의 기록으로 연구소 구역과 마지막 BIO CORE를 복구한다. 과거 대화의 이미지 제작 요청은 기존 에셋 참고로만 사용한다.

## 한 화면에 한 가지 중심 행동

- 1280×800, 1280×720, 1024×768 가로형을 우선한다. 상단은 홈·이전·지도 / 소리·설정, 중앙은 현상, 오른쪽은 현재 도구, 하단은 주요 행동이다.
- 지도 아래에 장소 목록을 반복하지 않는다. 지도 위 장소 버튼, 선택한 곳의 의뢰와 보상, 입장 버튼으로 구성한다. 잠긴 장소도 의뢰를 읽을 수 있지만 입장은 제한한다.
- 관찰과 기록 도구는 탭으로 나누고, 현미경의 보조 시야 조절과 원자료는 필요할 때 연다.
- 실시간 움직임과 고정한 A/B는 보기 전환을 사용한다. 자료 6개는 3개씩, 주장과 생활 영향 사건은 하나씩 조사해 긴 목록 스크롤을 줄인다.
- 아이콘에는 의미 있는 접근성 이름을 제공한다. 자주 쓰는 버튼에는 짧은 글자를 함께 둔다. 터치 대상은 기본 48px 이상이다.
- 단순 안내는 반복하지 않고 도움 버튼에서 모아의 의뢰·핵심 행동·보상을 확인한다. 큰 글씨는 내용을 자르지 않고 필요한 내부 스크롤을 허용한다.

## 종이와 다른 경험 및 보상

| 스테이지 | 직접 조작하고 발견하는 것 | 학생이 남기는 증거 | 완료 보상 |
|---|---|---|---|
| 균류 관찰 | Phaser 숲의 단서 탐색, 초점·밝기·확대 변화, 촬영과 특징 표시 | 표본별 촬영 상태·특징 표시·환경·설명 | 균류 관찰 패킷, 표본실 복구, 연못 입장 |
| 한 방울 탐구 | Phaser 스포이드 조작/옮기기, 움직임 재생·정지·시점 탐색, A/B 비교 | 채집 기록과 같은 대상의 다른 시점, 모양·움직임·장소 설명 | 비교 기록, 관찰소 복구, 자료실 입장 |
| 세균의 단서 | 원문 확인 후 Phaser 연결도에서 근거를 열고 연결/해제, 주장별 상태 변화 | 특징·장소 주장에 실제 연결한 원문 자료 | 세균 증거 프로필, 자료 통신망 복구 |
| 생활 속 사건 | Phaser 시간 지점 선택, 전후 고정과 변화 표시, 다른 상황의 영향 재검토 | 빵 변화의 시점 쌍·표시, 사건별 두 단서, 맥락 설명 | 생활 영향 보고서, 생활마을 연구등 복구 |
| 생명과학 작업실 | Phaser 작업대 배치, 연결, 예상 후 RUN, 설계에 따른 흐름 중단/완료 | 설계 버전·예상·실행 결과·비교와 설명 | BIO 설계도, 작업실 전원 복구, 최종 보고 개방 |

속도, 반복 클릭, 정답을 처음에 골랐는지로 보상하지 않는다. 오답 예상은 감점하지 않는다. 근거가 부족하면 기존 판정기가 구체적인 보완 행동을 알려 준다. 보상은 완료된 증거에서 파생하므로 재접속에도 복구 상태가 유지되고, 관리자 예시와 학생 기록은 분리된다.

## 마지막 행동

다섯 기록을 보고한 뒤, 학생이 자신의 기록을 열어 해당 포트에 연결하고 코어를 가동한다. 자동 엔딩으로 건너뛰지 않는다. 복구 중에는 각 기록을 회고하며 결과 화면으로 즉시 이동할 수도 있다. 결과의 소개 카드 PNG와 인증서 인쇄는 유지한다.

## 구현 및 자료 경계

지도·숲 단서·채집·근거 연결도·시간 탐색·조립·가동·코어는 Phaser 3의 2D 장면이다. 현미경 촬영/주석과 비교 증거 썸네일은 기존 Canvas 2D를 유지하며, 한글·도구·키보드 대체 입력은 DOM이 담당한다. 기존 Three.js 구현 파일과 의존성은 보존하되 현재 실행 경로에서는 불러오지 않는다.

새 생성 지도는 `public/assets/exploration-map.webp`에 적용했다. [생성 프롬프트](MAP_ASSET_PROMPT.md)는 별도로 보관한다. 과학 관찰 자료는 여전히 **설명용 모형**이며 실제 검수된 현미경 사진이나 동일 표본 시간 자료로 대체해야 한다. UI/기능 검증은 실제 학습효과 또는 교과 검수를 의미하지 않는다.

영상은 [별도 제작 캔버스](https://chatgpt.com/space/page_b460050fb99081919a7ca655d9b2e6c5)에 도입 6초, 엔딩 4초×2컷으로 정리했다. 영상이 없어도 전체 플레이가 가능하다. 제작 파일을 받은 뒤 재생·건너뛰기·동작 줄이기·로드 실패 대체를 연결한다.

## 검증

기존 판정 테스트, 프로덕션 빌드, 전체 학습 경로, PNG 다운로드 및 새로고침 복원, 태블릿 3개 크기의 15개 화면을 확인한다. 최종 실행 결과와 남은 자료·실기기 검증 범위는 `TABLET_VERIFICATION.md`에 기록한다.
