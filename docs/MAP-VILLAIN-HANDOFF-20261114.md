## 외형과 등장

**초점 도깨비 렌즈 / 보라 외눈 링, 어두운 렌즈 덮개와 밝은 현미경.** 스테이지 완료 기록 후 지도에 돌아올 때 해당 장소 옆에 등장한다. 기존 주인공·동료·건물의 스타일을 유지하고, 악당과 소품의 접점이 글 없이도 읽히게 그린다. 아래 소품 동작은 지도 위 짧은 장난 컷이다. 활동 화면이나 기존 학습 데이터에는 손대지 않는다.

기존 지도 악당·등장 좌표가 작업된 기록이 있다. 기존 에셋과 DOM 위치를 먼저 대조한다.

## 스테이지마다 바뀌는 소품·자세·대사

장소명은 기획상의 연결 기준이다. 활성 버전의 스테이지 ID와 이름을 대조한 뒤 키를 정한다. 선택 구역은 실제 별도 완료 이벤트가 있을 때만 추가한다.

| 장소 | 악당 스프라이트 동작 | 첫 등장 또는 접근 대사 예시 |
|---|---|---|
| 버섯숲 표본실 | 현미경 앞에 렌즈 캡을 갖다 대기 | “오늘은 아무것도 못 보겠지?” |
| 연못 관찰소 | 표본 창 앞에 불투명 덮개 흔들기 | “표본을 가리면 나만 보이지!” |
| 자료 연구실 | 기록 프레임을 90도 비틀기 | “파일은 옆으로 봐야지!” |
| 생활마을 | 진열 라벨을 바꿔 꽂기 | “이름표 바꾸기 성공!” |
| BIO 작업실 | 작업실 투영창 앞에 렌즈 드리우기 | “화면을 흐려 버릴 테다!” |

상황 대사 예시:

- 접근: “렌즈는 내가 닫았어!” / “무슨 표본인지 잘 안 보이지?”
- 1·2타: “앗, 초점이 흔들려!” / “덮개가 자꾸 빠지잖아!”
- 퇴장: “픽셀 몇 개만 챙겨 갈래!” / “덮개는 두고 간다!”

스테이지 고유 문장을 우선하고, 상황 대사는 연속 반복 없이 고른다. 주인공·보조 캐릭터의 주민 대화와 겹칠 때는 악당 말풍선을 생략한다.

## 세 번의 타격과 접촉 피격

| 사건 | 이 프로젝트의 표현 |
|---|---|
| 1타 · 짧은 명중 | 조리개 모양이 한 번 오므라듦 |
| 2타 · 더 큰 반동 | 투명한 격자가 비뚤어짐 |
| 3타 · 마무리와 퇴장 | 검은 캡이 떨어지고 보라 렌즈가 작은 픽셀로 접힘 |
| 주인공 접촉 | 주인공은 눈을 가리고 한 번 뒷걸음 |
| 보조 캐릭터 접촉 | 동료는 고개를 낮추고 짧게 기울었다가 회복 |
| 악당의 접촉 공격 동작 | 조리개 링을 한 번 좁혔다 열며 짧게 전진. 맞은 쪽에 사각 초점 모양이 한 컷 나타남. |
| 타격·퇴장 효과음의 차이 | 삑 → 찰칵 → 띠롱 |
| 접촉 효과음 모티프 | ‘삑, 찰칵’ |

세 타격은 같은 공격 입력이다. 가까이 있는 상태에서 한 입력이 한 타로 계산된다. 접촉 피격은 닿은 쪽만 재생하고 공격 카운트와 학습 진행에는 영향을 주지 않는 것을 권장한다. 소리를 꺼도 표정·자세·게이지로 읽혀야 한다.

## 방향과 시선

[공통 방향 규칙](../../_shared/MAP-VILLAINS-HANDOFF-20261114.md#방향시선공격-자세)을 적용한다. 외눈의 시선과 집게 팔이 상대 쪽을 향하되, 현미경과 렌즈 캡이 가려지는 관계는 유지한다.

## 제작하고 적용할 순서

1. 기존 진입점 확인: [src/mapData.ts](../src/mapData.ts) · [src/content.ts](../src/content.ts) · [docs/reviews/PLAY-REVIEW-20261110.md](../docs/reviews/PLAY-REVIEW-20261110.md). 활성 지도와 완료 상태, 실제 주인공/보조 지도 원본·이름, 기존 악당/스프라이트·대사·저장부터 확인한다.
2. 기본 악당 한 장, 위 표의 장소별 소품 동작 스트립, 공통 이동/접촉 전조/피격/퇴장 프레임을 제작한다. 주인공·보조 피격은 각각 4~6프레임. 소품이나 배경을 몸통 시트에 같이 구워 넣기 전에 지도 크기에서 알아볼 수 있는지 확인한다.
3. 별도 승인된 구현 단계에서 완료된 장소 좌표에 악당을 붙이고, 기존 HUD 근처에서 공격·타격·피격·퇴장만 연결한다. 기존 이동/화면 전환/복구 상태와 학습 완료/다음 장소 해금은 보존한다.
4. 완료 전/후, 정확한 3타, 두 아군의 개별 접촉, 퇴장 및 재진입, 빠른 연타, 무음·모션 감소·태블릿을 확인한다. 가장 작은 정상 지도 표시 크기에서 소품과 방해 동작이 구분되는지 본다.

완료된 것: 정적 이미지 합성과 계획. 남은 것: 기존 시트/캐릭터 일치 확인, 프레임 제작, 대사 최종화, 구현 및 테스트. 06 물의 상태 변화는 참고 전용.
