# 교사용 안내 · 생명 코드 연구소

## 1. 한 줄 소개

모아 연구원과 함께 버섯숲·연못·세균·생활마을·BIO 작업실 다섯 연구소에서 20개 탐구를 해 근거를 모으고, 마지막 BIO CORE를 복구하는 과학 탐험 게임입니다.

## 2. 대상

| 항목 | 내용 |
|---|---|
| 학년·학기 | 초등 4학년 1학기(운영 시트 「이예리 선생님」 탭, 2026-11-22 확인) |
| 과목·단원 | 과학 「다양한 생물과 우리 생활」(운영 시트 단원명). 교과서 단원 번호는 확인 필요. 앱이 근거로 적은 자료는 경기도교육청 「다양한 생물과 우리 생활」입니다. |
| 성취기준 | [4과12-01] 균류·원생생물·세균을 관찰하여 특징과 사는 곳을 설명할 수 있다. (M1·M2·M3) |
| | [4과12-02] 균류·원생생물·세균이 우리 생활에 미치는 영향을 조사하여 발표할 수 있다. (M4) |
| | [4과12-03] 우리 생활에 생명과학이 이용되는 사례를 소개하는 자료를 만들어 공유할 수 있다. (M5) |

## 3. 준비

- 기기: 가로 태블릿이 기준입니다. 전자칠판과 PC에서도 열립니다.
- 화면: 가로 화면. 1024×768, 1280×800, 1920×1080에서 확인했고, 낮은 가로 화면(1024×600, 915×412)에서는 일부 글이 줄거나 숨습니다.
- 소리: 모아와 마을 주민 목소리, 배경 음악, 효과음이 있습니다. 설정에서 켜고 끕니다.
- 인터넷: 첫 탐구를 조작할 수 있게 된 뒤부터 오프라인 저장이 준비되어, 와이파이가 끊겨도 새로 고쳐 이어 할 수 있습니다. 시작·마무리 영상은 오프라인 저장에서 빠집니다.
- 예상 시간: 설계 목표는 35~45분(`docs/PRD.md`)입니다. 실제 수업에서 시험하지 않았습니다. 확인 필요.

## 4. 차시 흐름

시작 영상 → 「모아의 의뢰」 → 지도에서 연구 시설 이동 → 연구소마다 탐구 4개와 개념 영상 → 다섯 연구소를 마치면 코어 복구 → 복구 이야기 → 최종 보고서와 인증서.

| 연구소 | 학생이 하는 일 | 배우는 개념 |
|---|---|---|
| M1 버섯숲 표본실 | 사진 속 장소 보고 표본 고르기, 돋보기와 현미경으로 포자 찾기, 곰팡이 이름표 붙이기, 같은 점·다른 점 분류 | 균류, 균사, 포자 |
| M2 연못 관찰소 | 물 한 방울 채집, 해캄 초점 맞추기, 짚신벌레 두 순간 비교, 관찰 기록 정리 | 원생생물의 생김새와 움직임 |
| M3 자료 연구실 | 배율 바꿔 세균 찾기, 모양별로 표본병에 넣기, 면봉 채집과 배양 접시 비교, 세 생물 크기 순 전시 | 세균의 크기·모양·사는 곳 |
| M4 생활마을 | 빵과 낙엽의 변화 찾기, 생활 사건을 도움·피해로 분류 | 같은 생물도 상황에 따라 영향이 다름 |
| M5 BIO 작업실 | 요구르트 만들기, 빵 반죽·낙엽 처리 설계, 소개 카드 만들기 | 생물의 작용을 이용하는 방법(재료 → 작용 → 결과) |

지도에서 다섯 연구 기록을 모으며 각 연구소의 악당을 세 번 물리치면 성취 카드를 받습니다.

## 5. 정답과 판정 기준

| 활동 | 정답 또는 통과 조건 |
|---|---|
| M1-1 | 숲속 죽은 나무 → 버섯 표본, 축축해진 빵 → 곰팡이 표본 |
| M1-2 | 갓 아래 주름 찾기, 주름의 포자 3개 누르기 |
| M1-3 | 초점 다이얼을 65 근처로 맞추기. 이름표 「균사」는 가는 실, 「포자주머니」는 동그란 주머니 |
| M1-4 | 갓 아래 주름: 버섯에만 / 실 끝 동그란 주머니: 곰팡이에만 / 가는 실로 된 몸: 둘 다 / 포자로 퍼져요: 둘 다 |
| M2-1 | 물가 가까이·물풀 가까이 둘 다 인정. 채집 → 옮기기 순서 |
| M2-2 | 초점 65±12, 밝기 40~85에서 사진 남기기 |
| M2-3 | A 고정 뒤 3칸 이상 떨어진 순간을 B로 고정. 가는 털은 몸 둘레 |
| M2-4 | 관찰 기록 정리(고르는 정답 없음) |
| M3-1 | 1000배 시야에서 짚신벌레 가장자리 옆 작은 알갱이 찾기 |
| M3-2 | 동그란·알갱이가 이어진 세균은 공 모양 병, 길쭉한·꼬리 달린 세균은 막대 모양 병, 꼬불꼬불한 세균은 나선 모양 병(병마다 2마리) |
| M3-3 | 5곳 중 3곳 이상 채집, 배양기 시간을 3일째까지, 「세균은 손·흙·물·물건처럼 여러 곳에 살아요」 선택 |
| M3-4 | 버섯 → 짚신벌레 → 세균 순. 세균은 짚신벌레보다 훨씬 작고, 공·막대·나선처럼 여러 모양이 있으며, 흙·물·손처럼 여러 곳에 삶 |
| M4-1·4-2 | 처음과 나중을 비교해 빵에 새로 생긴 곰팡이 자리, 낙엽에서 사라진 잎 자리 누르기 |
| M4-3 | 먹으려던 빵의 곰팡이는 피해, 요구르트 만들기·낙엽 분해·물속 먹이 관계는 도움 |
| M4-4 | 빵 반죽 만들기는 도움, 충치는 피해 |
| M5-1 | 우유를 재료 칸, 유산균 가루를 작은 생물 칸, 요구르트를 만들 음식 칸에. 물은 어느 칸에도 넣지 않음 |
| M5-2 | 효모의 작용을 고름. 「요구르트 만드는 세균」은 정답 아님 |
| M5-3 | 「균류·세균의 분해 작용」을 고름. 「분해가 멈춘 낙엽」은 정답 아님 |
| M5-4 | 요구르트는 유산균, 빵 반죽은 효모, 낙엽 분해는 균류·세균의 작용 |

틀리면 오답 문장과 토토 힌트가 나오고 다시 고를 수 있습니다. 11-21 이후 M4·M5-1의 화면 문구(분류 단추 이름 「도움을 줘요」「피해를 줘요」 등)가 바뀌어 `docs/TEACHER-REVIEW-20261121.md`의 문장과 다를 수 있습니다. 정답 요지는 같습니다.

## 6. 수업 팁

- 막히는 곳: 현미경은 맨눈 → 돋보기 → 현미경 순서로 키워 봅니다. 초점 다이얼은 선명해질 때까지 천천히 돌립니다. 받지 못한 배지는 발견 도감의 다시 도전으로 받을 수 있습니다.
- 되묻기: 「이 생물은 어디서 찾았고, 어떤 모양이었을까?」 「같은 곰팡이도 이로울 때와 해로울 때가 있었지. 어떤 상황이었어?」 「생물은 어떤 작용을 해서 요구르트·빵을 만들까?」
- 전체 수업에서는 전자칠판으로 연구소 하나를 함께 하고 근거를 말로 설명하게 합니다. 모둠에서는 탐구마다 조작 담당과 기록 담당을 나눕니다.
- 설정 → 교사용 가이드 → 교사용 도구에서 「모든 단계 한 번에 열기」「시연용 예시 기록 불러오기」「큰 글씨」「동작 줄이기」를 씁니다. 시연 기록은 학생 기록과 따로 지워집니다.

## 7. 저장과 다시 하기

- 진행은 이 기기·브라우저·접속 주소의 IndexedDB에 저장됩니다. 서버로 보내지 않고, 다른 기기로 이어지지 않습니다.
- 수업에서는 항상 운영 주소를 씁니다. 로컬이나 미리보기 주소의 기록은 운영 주소에 섞이지 않습니다.
- 처음부터 다시 하려면 설정 아래쪽 「연구 기록 초기화」 → 「기록 지우기」를 누릅니다. 진행, 보상, 관찰 사진, 표시, 설명과 설계 기록이 지워지고 소리 설정은 남습니다.
- 인증서는 「나는 이제 … 할 수 있어요」 문장을 고른 뒤 「인증서 인쇄 / PDF 저장」으로 출력하고, 「내 카드 저장」으로 카드 그림을 받습니다.
