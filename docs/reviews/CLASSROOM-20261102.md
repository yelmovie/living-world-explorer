# 생명 코드 연구소 수업 점검 · 2026-11-02

초등학교 3~4학년군 과학 「다양한 생물과 우리 생활」의 성취기준 세 가지를 게임의 20개 활동, 최종 보고서, 소개 카드와 대조했다.

| 탐구 | 학생이 직접 남기는 근거 | 점검하고 고친 부분 |
| --- | --- | --- |
| 균류 관찰 · 4과12-01 | 버섯과 곰팡이가 발견된 곳, 주름·포자·균사가 보이는 위치 | 죽은 나무 속 균사를 실제 그림과 일치시켰다. 둥근 포자주머니는 관찰한 곰팡이의 특징으로 설명한다. 효모까지 가는 실로 이루어졌다고 일반화하지 않는다. |
| 한 방울 탐구 · 4과12-01 | 채집 장소, 해캄의 모양과 짚신벌레의 두 시점 위치 | 학생이 채집 장소를 고르고, 현미경 사진에 특징을 직접 표시한다. 자동재생으로 장비 준비나 움직임을 살펴볼 수 있다. |
| 세균의 단서 · 4과12-01 | 자료에서 찾은 생김새와 사는 곳, 판단을 바꾼 근거 | 생성 그림을 설명용 모형으로 표시했다. 크기 사다리는 두 예시 표본의 비교이고, 보이는 정도는 현미경과 표본의 조건에 따라 달라진다. |
| 생활 속 사건 · 4과12-02 | 전후에 달라진 곳, 생활에 미친 영향, 친구에게 들려줄 조사 결과 | 관찰 순서와 실제 날짜를 구분한다. 분해에 어떤 생물이 관여했는지는 조사 자료로 확인한다. 발표는 학생이 조사한 생활 사례에서 시작한다. |
| 생명과학 작업실 · 4과12-03 | 선택한 사례의 재료와 생물 작용, 설계 결과, 나만의 소개 카드 | 요구르트의 신맛, 효모가 반죽을 부풀리는 까닭, 낙엽 분해를 퇴비 만들기에 이용하는 사례를 구분한다. 카드를 저장한 뒤 짝에게 보여 주고 설명하도록 연결했다. |

## 수업에서 확인할 것

교실에서는 실제 버섯이나 연못물 표본을 관찰하고, 출처가 확인된 현미경 사진·영상과 게임의 모형을 비교한다. 발표와 공유는 짝과 직접 진행한다. 브라우저 점검에는 초등학생 사용성 관찰이나 실물 기기 실험이 포함되지 않았다.

## 검증 범위

- Windows의 Chromium에서 15개 경로를 6개 화면 크기로 확인했다. 가로 넘침, 화면 밖의 하단 조작, 작은 터치 대상, 이미지 요청 실패를 검사했다.
- 전체 20개 활동에서 7곳은 선택형 관찰 재생을, 13곳은 학생 직접 응답을 사용한다. 재생을 중간에 멈췄을 때 기존 표시와 선택이 보존되고, 끝까지 재생해도 학생의 답·발견·보상이 대신 기록되지 않는지 검사했다.
- 교사용 전체 해금으로 지도 5곳과 각 4개 활동에 진입했다. 빈 시연 기록, 예시 불러오기, 시연 초기화, 종료와 새로고침에서 학생 저장 기록이 보존되는지 확인했다.

교육과정 원문은 [교육부 2022 개정 교육과정 고시](https://www.moe.go.kr/boardCnts/viewRenew.do?boardID=141&boardSeq=93458&lev=0&m=0404)와 [경기도교육청 성취기준 자료](https://www.goe.go.kr/resource/goe/na/bbs_2675/2025/11/b05e123f-8c12-4929-9914-319dea9b2099.pdf)에서 확인할 수 있다. 과학 내용은 [균류의 특징과 효모](https://openstax.org/books/biology-2e/pages/24-1-characteristics-of-fungi), [미국 국립치의학연구소의 충치 과정](https://www.nidcr.nih.gov/health-info/tooth-decay/more-info/tooth-decay-process), [미국 환경보호청의 퇴비화 설명](https://www.epa.gov/recycle/composting-home)을 함께 참고했다.
