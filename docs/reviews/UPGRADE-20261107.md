# 8번 생명 코드 연구소 개선 검토

## 범위와 결론
기존 변경을 보존한 국소 개선이다. 커밋·배포·설치하지 않았다. 1~5번과 다른 프로젝트를 수정하지 않았다. 최종 납품 승인이나 전 기기 통과 판정은 아니다.

## 적용
- 저장을 못 해 메모리에서만 진행할 때 경고가 빠지는 결함 수정. 임시 저장·사진 누락·원본 보호·다른 창 충돌·저장 실패를 닫기 전 읽을 수 있는 대화상자로 표시하고 설정에 현재 상태 표시. `src/storage-status.ts`, `src/main.ts` showStorageWarning, `src/settings.ts`.
- 일반 GET으로 불러오는 선택 GLB와 JS가 최초 온라인 열람 후에도 캐시에 남지 않는 결함 수정. 성공 응답만 콘텐츠 해시 키에 저장하며, 저장 용량 부족은 온라인 관찰을 막지 않음. `public/sw.js` cachedFile.
- 기존 첫 제출 배지는 유지하되, 틀린 뒤 근거를 재확인해 완료한 탐구도 발견 도감에 격려 표시. 완료 여부와 현재 검증을 함께 확인하므로 미완료/잘못된 기록은 인정하지 않음. `src/experience.ts` revisedEvidenceCount, `src/main.ts` records.
- 관찰 조작 대화상자 가로화면을 그림/조작 두 열로 개선한 이전 작업 유지. 짧은 가로화면 버튼과 확대 버튼·슬라이더 증감에 48px 최소 터치 영역. 증감 버튼에 도구별 접근성 이름. `src/styles.css`, `src/ui.ts`.
- 선택 3D 뷰어 DPR 1.5 상한, 탭이 숨겨지면 RAF 중단, 다시 보이면 재개, dispose 시 리스너 제거. `src/model-viewer.ts`.
- 외장 SSD AppleDouble `._*`를 Vitest에서 제외. 메타데이터를 지우지 않고 일반 테스트 명령의 실패를 해결. `vite.config.ts`.

## 학습 흐름과 중복 판단
M1 확대·초점·특징 표시는 형태 관찰, M2 채집·시간 정지·두 시점 비교는 움직임, M3 원문 연결과 판단 변경은 자료의 증거성, M4 시간과 생활 맥락 비교는 이로움/해로움, M5 배치·연결·예상·실행은 활용 설계다. 4개 소활동의 공통 제출 구조는 반복되지만 핵심 조작과 판단 목적은 다르다. M5 실행 스냅샷의 예상·조건 기록 및 M3 첫 판단/새 근거 구분은 기존 구현을 유지했다. 반복 클릭을 늘리는 새 단계는 추가하지 않았다. 성취기준의 최종 정합성은 교사 검토가 필요하다.

- Vitest 11파일 128테스트 통과. 새 저장 경고 8사례와 재확인 격려 1사례 포함.

- TypeScript noEmit 통과. Vite 프로덕션 빌드 성공. git diff --check 통과(기존 CRLF 정규화 경고만).
- 이번 연속 작업 전반부 CUA 검증: 320×568,375×812,768×1024,830×515,915×412,1024×768,1280×800 관찰 대화상자 가로 넘침 없음. 5개 단계 첫 화면×375/915에서 가로 넘침·깨진 DOM 이미지 없음. 버섯과 시간 관찰의 실제 조작 제출 확인. 증거는 `.tmp/responsive-20261107/REVIEW.md`와 이미지.
- 주의: 후반부 48px 추가·저장 대화상자·RAF 변경 뒤 같은 화면 검사를 다시 수행하지 않았다. 전체 20활동 완주, 실제 iPad/Safari, 화면낭독기, 첫 로드 시간/FPS는 이번에 측정하지 않았다.
- graphify AST 인덱스 갱신 완료. 기존 소스 백업은 `.tmp/series-upgrade-20261107/`에 보존.

## 이미지·모모 상태
기존 학습 이미지와 장소/NPC 이미지가 있어 새 이미지로 교체할 근거가 없었다. 11개 효과음과 2개 BGM을 유지했다. 8번에는 NPC 음성 파일이 없고 다른 프로젝트의 설명 음성은 내용이 달라 재사용하지 않았다. 모모 상태 API가 HTTP 401로 읽히지 않아 유휴/큐 확인 불가. 인증 정보를 읽거나 우회하지 않았으며 무거운 새 음성을 생성하지 않았다. NPC 대사는 텍스트로 읽을 수 있다. 새 생성 파일이 없어 삭제 대상도 없다.

## 후속 개선 프롬프트
1. 현재 저장 원본·교사 시연 분리를 보존하라. 저장소 사용 불가, quota, 다중 탭 충돌에서 경고와 설정 상태를 실제 브라우저로 검증하고 학생 기록 덮어쓰기를 금지하라.
2. 실제 프로덕션 SW로 GLB 한 번 열기→오프라인 재열기→신버전 콘텐츠 해시 교체를 검증하라. 선택 3D 없이도 모든 학습을 완료할 수 있게 유지하라.
3. 320px 세로·915×412 가로·iPad에서 48px 버튼, 그림 좌표, 키보드 순서, 대화상자 스크롤/닫기를 재검증하라. 20활동의 조건 변경·증거·첫 예상 보존을 끝까지 플레이하라.
4. 모모의 정상 로그인 화면에서 유휴/큐를 확인할 수 있을 때만 NPC별 짧은 인사 5개를 생성하라. 음소거·자막·다시 듣기·중복 재생 중단과 탭 숨김 정지를 함께 구현하라. 외부 서비스 전송이나 인증 우회는 하지 말라.
5. 실제 태블릿의 냉간 로드 시간, DPR1.5 3D 프레임·메모리를 측정하고 기록하라. 점수 상승을 선언하기 전에 미측정 상태를 해소하라.
