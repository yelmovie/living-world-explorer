# 스테이지 반응형·학습 장면 개선 점검

2026-11-08 · 5개 스테이지, 20개 탐구 활동

요청 범위의 수정과 브라우저 점검을 완료했다. 9가지 화면 크기의 180개 활동 화면에서 검사한 글자·그림·완료 배지 겹침, 가로 넘침, 조작 영역 접근 실패는 0건이다. 실제 학교 태블릿과 Safari의 성능·터치 동작은 이번 점검에 포함하지 않았다. 이 기록은 스테이지 UI 개선 검증이며 전체 배포 판정을 대신하지 않는다.

## 적용 내용

| 대상 | 변경과 학습상의 효과 |
|---|---|
| 공통 화면 | 제목과 미션 그림의 공간을 분리했다. 짧은 가로 화면은 보조 문구를 줄여 관찰 높이를 확보하고, 폴드 가로는 관찰·도구를 나란히 배치했다. 세로 폰은 불필요한 관찰 여백을 없애 도구가 빨리 보이게 했다. |
| M1 균류 | 관찰 자료의 그림·이름·완료 표식을 독립된 칸으로 배치했다. 관찰 도구의 번호와 이름을 분리하고, 긴 관찰 노트는 글자 높이만큼 공간을 확보한다. |
| M2 한 방울 탐구 | 장소 선택→한 방울 채집→유리판 준비의 진행을 번호·문구·완료 표시로 보여 준다. 채집 사진, 스포이드, 받침 유리판의 역할을 구분했다. |
| M3 세균 | 연결된 근거의 수와 원본 썸네일을 확인할 수 있다. 자료 검토 장면의 번호·사진·제목·읽음 상태를 분리했다. 좁은 도구 패널의 긴 주장은 한 열로 읽는다. |
| M4 생활 속 사건 | 전후 사진과 시간 버튼을 분리하고 A·B 출처와 변화 표시 위치를 구분했다. 겹쳐 보기 슬라이더의 실제 값이 드래그와 ± 버튼 모두에서 갱신된다. |
| M5 작업실 | 재료→생물의 작용→결과 순서를 표시하고 카드 그림과 긴 이름의 공간을 분리했다. 큰 글자로 카드를 읽고 연결하는 기존 대체 조작을 패널 위로 올렸다. 발효 시계와 완성 음식을 분리하고 조립 확인 알림이 실험 결과를 덮지 않도록 창 안에서 확인한다. |

짧은 가로 연결 보드에서 내용이 길어지면 보드 안에서 세로 스크롤한다. 하단 기록·단계 버튼은 별도 공간에 유지한다. 스크롤이 필요한 화면에만 안내와 화살표를 표시한다. 원본 자료 카드 위의 세로 스와이프, 가로 드래그, 탭·키보드 연결 경로를 지원한다. 스크롤 영역의 가장자리에서 일부 카드가 보이지 않는 것은 의도된 클리핑이며, 실제 스크롤 후 버튼의 중심점에 접근할 수 있는지도 검사했다.

## 수정 파일

- `src/styles.css`: 공통 제목·하단·폴드·폰 레이아웃
- `src/scenes/inquiry.ts`, `src/inquiry-controls.css`: 질문·선택지 그룹, 선택 표시, 도구 단계·값, 큰 글자 조립과 창 안의 확인 문구

- `src/renderers/inquiry2d.ts`: 채집·전후 비교·자료·작업대·발효 장면
- `tests/stage-layout.mjs`, `tests/stage-states.mjs`: 실제 글자·아이콘 배치 및 상태·터치 회귀 검사
- `docs/DESIGN_SYSTEM.md`: 스테이지 반응형·학습 장면 계약
