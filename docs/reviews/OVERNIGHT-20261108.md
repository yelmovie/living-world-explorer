# 다양한 생물: 야간 증분 검토 · 2026-11-08

## 실제 변경
- 새 생성 그림 **0개**. 기존 균류·원생생물·세균·생활 영향·활용 설계 그림을 그대로 유지했다.
- `src/ui.ts`: 관찰 순서/전후 겹쳐 보기/표시 위치 슬라이더에 현재 값 표시를 추가하고 최솟값·최댓값에서 증감 버튼을 비활성화했다. 버튼을 감싸던 label을 div로 바꿔 원치 않는 라벨 활성화를 방지했다.
- `src/styles.css`: 슬라이더 수치 가독성과 최소 조작 크기, 낮은 태블릿의 발견 단계 버튼 48px 확보.
- 873×580에서 현재 발견 버튼의 자동검사 경계값 실패를 재현·수정하고 전체90화면을 재검사했다.

## 5단계 시각 검토
- 균류: 갓·주름·균사·곰팡이 표본 이미지와 돋보기/현미경 전환 유지.
- 원생생물: 해캄/짚신벌레의 관찰 그림과 움직임·시점 자료 유지.
- 세균: 공/막대/나선 모형과 증거 자료 유지. 생성 그림을 실제 현미경 사진으로 표현하지 않음.
- 생활 영향: 빵/낙엽의 동일 표본 시간 변화와 비교 기록 유지.
- 생명과학 활용: 예측→설계→가동→결과 대조 구조와 기존 그림 연결 카드 유지.
