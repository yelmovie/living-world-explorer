## 실제 검증과 범위

- 단위 검사 68개(카드 내보내기 회귀 4개 포함)와 타입 검사가 통과했어요. 마지막 소스의 TypeScript 검사 + Vite 프로덕션 빌드도 통과했어요(37모듈, 13.77초).
- 20개 활동의 학생 완주, 발견 보상 10개, 최종 보고 5기록 확인, 코어 5포트 연결, PNG 다운로드, 한글 제목/소개 복원을 확인했어요. 추가로 요구르트·빵 반죽·낙엽 분해를 각각 실제 PNG로 저장하고 저장된 학생 원본이 바뀌지 않는지 대조했어요. 마지막 기록 화면 보강 후 보고서의 실제 관찰 캔버스 2개(82×78px), 도감의 관찰 캔버스 6개, 사진 크게 보기(698×392.6px)를 확인했어요. 원래 초점·밝기·확대·이동·특징 표시를 복원하며 표시 1곳/2곳과 기록이 일치했어요.
- 같은 기록에서 시연용 예시를 열고 소개 문장을 바꾸고 시연 기록을 초기화한 뒤에도 저장된 학생 원본은 동일했어요. 시연 종료·새로고침 뒤 원래 결과로 돌아왔어요.
- 저장 원본이 null·미래 버전·잘못된 구조일 때 자동 저장과 새로고침을 반복해도 원본이 보존됐어요. 오래된 다른 창의 쓰기는 IndexedDB 트랜잭션에서 차단되고 화면 알림이 표시됐어요. 실제 학생 기록을 사용하지 않은 격리 테스트예요.
- 1024×768, 906×755, 1280×800, 1920×1080, 873×580, 1280×720에서 각 15화면을 열었어요. 가로 넘침·핵심 하단 버튼 잘림·캔버스 영역 소실·깨진 이미지·런타임 오류는 0건이었어요. 최종 제목 대비 수정 뒤 873×580 M1/M3와 보상 예고를 추가 확인했어요. 새 교사용 시연 종료 버튼도 실제로 눌러 학생 기록이 동일하게 돌아오고 시연 표시가 사라지는 것을 확인했어요.
- 설정의 소리 스위치, 음량 잠금, 도입 다시 보기, 앱 정보, 학생·교사 가이드, 성취기준, 도구, 자료 출처에 실제 진입했어요. 출처의 외부 링크는 0개였어요. 완료 전 엔딩·인증서 잠금도 확인했어요.
- 설치된 Google Chrome에서 개념 영상 M1~M5 각각 12초 전체를 끝까지 재생했어요. 기존 수동 설치 Chromium은 H.264를 지원하지 않아 대체 설명이 표시됐고, 이를 Chrome 재생 실패로 혼동하지 않았어요. 소리 충돌은 Web Audio 활성 음원 수로 측정했으며 청감 평가는 하지 않았어요.
- 로컬 첫 화면 1.29MB × 30명 = 약 38.77MB예요. 요청 33개에는 개발 서버용 요청이 포함돼요. 이 수치로 실제 교실 동시 접속 시간을 단정하지 않았어요.
- 이미 열어 둔 탐구 화면은 오프라인에서 힌트를 조작할 수 있었지만, 오프라인 새로고침은 실패했어요. 다시 연결하면 정상으로 돌아왔어요. PWA·서비스워커를 새로 구현하지 않았어요.
- 자산 66파일, 약 5.86MB. 이미지 1MB 초과 0개, 영상 5개 합계 약 0.85MB. 이전 방향 이미지의 중복 1쌍은 목록만 남겼고 파일은 삭제하지 않았어요.
