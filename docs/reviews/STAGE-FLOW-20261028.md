# 스테이지 학습 흐름 개선 · 2026-10-28

상태: **로컬 구현·자동 검증 완료**. 초등 학습자가 태블릿에서 판단과 관찰에 집중하도록 반복 준비·확인 조작을 줄였다. 5개 스테이지와 20개 활동은 유지했다. 실제 태블릿 수업과 교실망 검증, 운영 배포는 이번 결과에 포함하지 않는다.

분류·수집·연결의 자료 카드는 **37장 → 27장**으로 줄었다. M1-1 4→2, M1-4 6→4, M3-1 4→2, M3-3 5→3, M4-4 4→2다. 카드를 줄였다는 수치는 실제 전체 터치 횟수나 수업 시간 감소를 실측한 값이 아니다.

## 준비하는 것과 학생이 판단하는 것

준비 상태는 `src/inquiry-preparation.ts`에서 새 기록을 만들 때만 적용한다. 현미경 도구·초점, 비교 기준 A, 두 번째 이후 설계의 재료·결과를 제공한다. 특징의 위치, 두 번째 시점, 분류 대상, 생물의 작용, 주장과 근거, 실행 전 예상과 결과 비교는 학생이 선택한다.

흐름선 자동 연결은 인접한 두 칸이 채워졌다는 표시다. 틀린 생물이나 재료를 놓아도 선은 이어질 수 있으며, 성공 판정은 별도로 실제 카드 조합을 확인한다. 자료가 펼쳐졌다는 기록은 읽기 시간이나 실제 이해를 측정한 값이 아니다. 제시된 자료와 정답 연결, 관찰 위치 등의 결과를 함께 판정한다.

자료는 옆 패널에 표시하고 드래그 또는 자료·대상 연속 탭으로 배치한다. 잘못 연결한 카드는 정답 체크 표시를 받지 않으며 다시 배치할 수 있다. 버튼 대체 조작도 같은 배치 함수를 이용한다. 크기 사다리의 잘못된 “매 칸 약 10배” 설명은 크기순 비교와 칸마다 다른 비율로 정정했다.

## 저장 호환과 상태 처리

- 새 준비 상태는 기존 기록이 없을 때만 만든다. 저장한 초점·표시·선택·시점 기록을 준비값으로 덮어쓰지 않는다.
- 줄인 카드는 현재 완료 조건에서 제외한다. 기존 객체에 남아 있는 카드 값은 삭제하지 않는다. 종전 `v` 및 `since: 2` 판정 구조는 유지한다.
- 이전 설계에서 채운 칸의 연결선만 자동으로 동기화한다. 실제 설계가 달라지면 예상·결과·비교를 무효화하고 재실행을 요구한다. 동일한 카드를 같은 칸에 다시 놓는 입력은 완료한 실행을 지우지 않는다.
- 소개 사례를 바꿀 때 이전 작용·문장을 지우고 새 사례 근거를 연결한다. 같은 사례를 다시 누르면 작성 내용을 유지한다.
- 실행 중 조작 차단, 이탈한 실험의 중단 기록, 중복 발견 모달 방지, 코어 중복 연결·중복 종료 방지를 적용했다.

기존 기록의 버전 호환, 새로고침 복원, 학생·교사 시연 분리, 다시 도전 후 기존 증거·보상·소개 카드 보존을 회귀 검사했다. 다시 도전도 같은 준비 로직을 사용한다. 처음 생각이 없는 이전 세균 기록은 선택 단계로 돌아가 재탐구할 수 있다.

검증 산출물은 Git 제외 경로 `.tmp/full-flow.json`, `.tmp/browser-audit.json`, `.tmp/review-after/interactions.json`, `.tmp/streamlined/checks.json`과 각 폴더의 화면 캡처에 있다. 콘솔 실행 오류 및 정상 흐름의 파일 요청 실패는 0건이었다. 헤드리스 브라우저의 소프트웨어 WebGL 경고 1종은 남아 있다.

최초 완주 검사에서 터치 직후 마우스 입력을 섞어 Phaser의 합성 마우스 억제에 걸렸다. 같은 좌표를 터치하면 정상 진입하는 것을 재현한 뒤 완주 검사의 캔버스 입력을 터치로 통일했다. 삭제한 중복 카드를 참조하던 이미지 테스트 2건도 현재 자료로 바꿔 의미·이미지 구분 검증을 유지했다.

독립 리뷰에서 찾은 재도전 준비 상태 누락, 캔버스/버튼 채집 단계 불일치, 이전 세균 기록의 처음 생각 선택 막힘을 수정했다. 타임라인 보조 표시 조작은 미리보기에서 고정한 전후 비교로 돌아간 뒤 표시하도록 맞췄다. 신규 이미지·의존성·외부 서비스는 추가하지 않았다. 실제 수업에서의 흥미·소요시간·학습 성취는 별도로 관찰해야 한다.
