## 확인과 수정

### P0 · 5-1 발효기

원본 렌더러에서 일반 탭 후 4초를 기다려도 ‘따뜻하게… 시간이 흐르고 있어요’, `running` 상태, 잠긴 재료 4개가 남는 것을 재현했다. 원본은 누르고 있는 동안 프레임마다 `1/150`을 더하며, 손을 떼면 프레임만 취소하고 실행 상태는 남겼다. 갱신 때 `panel.replaceChildren`으로 버튼도 다시 꽂았다.

- 시작·진행·완료·중단 후 재시도를 나눴다. 한 번 누르기, 짧게 눌렀다 떼기, Enter/Space 및 접근성의 native click으로 실행한다.
- `performance.now()` 경과 시간 2.5초를 기준으로 완료한다. RAF와 완료 타이머가 같은 멱등 완료 경로를 사용하므로 느린 프레임과 중복 입력이 실행을 늘리지 않는다.
- 실행 버튼은 mount 동안 계속 연결되어 있다. refresh는 표시·비활성 상태만 바꾼다. 누름 해제·터치 취소가 시뮬레이션을 멈추지 않는다.
- 탭 숨김·경로 이탈·새로고침 뒤에는 재료와 예상을 보존한 중단·재시도 상태를 제공한다. 복원한 오래된 `running`도 `interrupted`로 복구한다.
- 10초 초과 시 기다림이 길어진 이유와 재시도를 표시한다. 숨김 이벤트를 처리하고 타이머·리스너를 정리한다.
- 잘못된 세 재료 조합은 이유를 화면에 남긴다. 실패·중단 실행 기록을 보존하며 다시 실험한다. 예상이 결과와 달라도 정상 재료의 성공과 다음 활동을 막지 않는다.
- 짧은 가로 화면에서는 결과 단계의 예측 선택지를 접고, 재시도를 먼저 보여 준다. 긴 이유는 패널 안에서 읽는다.
- ‘시간과 변화를 줄여 보여 주는 학습 모형’, ‘실제 조리·섭취 안내가 아님’을 표시한다.

저장 형식과 기존 완료 판정은 유지했다. 회귀에서 각 사례의 성공 실행 1건·완료 저장 1회·다음 활동(M5-2) 진입을 확인했다.

### P1 · 1~4장

- 1장: 관찰·발견 설명과 3D 모형 안내를 ‘이 버섯 모형에서는 갓 아래 주름을 볼 수 있어요’로 한정했다. 작은 포자를 정밀하게 누르는 방법과 함께 큰 관찰 확인 버튼(터치/Enter)을 제공했다. 915×412에서 기존 CSS가 이 버튼을 숨기던 문제도 수정했다. 3D 로딩 실패 시 그림을 보여 주는 경로는 이미 있어 중복 수정하지 않고 실패 주입으로 확인했다.
- 2장: 기존 두 시점 비교와 몸 안쪽/몸 둘레 오답 근거를 유지했다. 자동 이동 중임을 안내하며, 완료된 비교는 학생이 직접 기록 버튼을 누를 때까지 유지한다.
- 3장: 최신판은 11월 17일 재설계된 확대·모양 분류·배양·전시 활동이다. 이전 카드 화면을 다시 만들지 않았다. 배양 오답 힌트는 실제 고른 표본 이름에서 생성한다. 손바닥·화분 흙·연못 물을 골랐을 때 문손잡이가 나오지 않는다. 전시에서는 맞게 놓은 카드가 남고 잘못 놓은 카드만 돌아온다.
- 3장: 배율 숫자·슬라이더 `aria-valuetext`·관찰 창 접근성 이름은 같은 값에서 나온다. 표시가 1000에서 멈출 때도 일치한다. ‘1000배여야 보인다’는 일반화를 ‘이 학습 모형의 1000배 시야’로 고치고 실제 관찰은 표본과 현미경 상태에 따라 달라짐을 알린다. 두리의 옛 배율 주장 음성은 연결하지 않는다.
- 3장 정리 영상: 기존 흙·치아 영상을 유지하고 화면 및 접근성 설명에 ‘이번에 고른 배양 접시와 다른 별도 예시’라고 표시한다. 안내가 영상 조작 버튼을 가리지 않도록 독립된 줄을 확보했다. 현재 영상은 효과음만 있으며 캐릭터 낭독은 없다. 기존 자막/VTT/fallback 문장은 같은 흙·치아 예시를 설명한다.
- 4장: 효모·충치 등 도움·피해 사례와 사진/밀봉 표본 안전 문구는 유지했다. 기존 게임 조작·오답 복구 검사로 회귀를 확인했다.

배율 표현은 [Nikon MicroscopyU의 분해능 설명](https://www.microscopyu.com/microscopy-basics/resolution)을 참고했다. 실제 세부 관찰은 배율만으로 결정되지 않고 렌즈·조명·표본 대비 등에도 영향을 받는다. 교과 학습 효과를 실험으로 입증한 결과는 아니다.

## 남은 확인

- 실제 가로 태블릿 터치, iPad Safari, 기기별 백그라운드/느린 CPU·프레임 동작은 미검증이다.
- 수정한 일부 과학 요약·토토 힌트·두리 대사는 일치하는 새 녹음이 없어 글로 표시한다. 기존 녹음 파일과 캐릭터 에셋은 보존했고, 다른 내용의 옛 녹음을 새 대사로 가장해 재생하지 않는다. 납품 시 변경 대사의 녹음 보완이 필요하다.
- 이 헤드리스 환경에서 M3 개념 영상은 대체 텍스트 화면도 관찰됐다. 별도 예시 안내와 대체 설명은 확인했지만 실기기 영상 재생·탐색·전체 음성 청취는 별도 확인이 필요하다.
- 원격 push·배포는 승인 범위 밖이므로 수행하지 않았다. 운영 사이트에는 이 로컬 수정이 반영되지 않았다.
