# 탐구 화면 한 화면 구성·자동재생 개선

2026-11-08 · 5개 스테이지, 20개 활동

실험 장면과 현재 조작, 기록 버튼을 스크롤 없이 한 화면에 배치했다. 동일한 안내를 반복하던 도구 단계·상세 설명·보조 버튼을 정리하고, 현재 단계의 조작만 보여 준다. 기존 학습 기록·정답 판정·해금 규칙과 작업 중이던 다른 변경은 유지했다.

## 적용 내용

- 가로 화면은 실험과 조작을 나란히, 세로 화면은 위아래로 구성한다. 관찰 그림과 현미경 시야도 확대했다. 하단의 이전·도움말·단계·기록 버튼은 실험 영역 밖의 고정 행에 둔다.
- 연결 보드의 모든 자료와 기록 칸을 한 화면에 배치한다. 완료 표시는 사진 쪽에 두어 긴 이름을 밀어내지 않는다. 선택한 자료를 읽는 동안에는 중복된 진행 안내를 숨긴다.
- 현미경 촬영 뒤 표시, 시간 고정 뒤 비교, 자료 확인 뒤 주장·근거 선택, 사례 선택 뒤 작용·소개 문장 순으로 현재 조작을 보여 준다. 긴 도움말·조사 자료는 별도 창에서 읽는다. 큰 글씨 설정을 실제로 켜서도 확인했다.
- 자동재생 옆에서 0.5·1·1.5·2배를 고른다. 재생 중 속도 변경과 멈추기를 지원하며, 같은 속도가 짚신벌레 움직임과 발효·설계 가동에도 적용된다. 선택한 속도는 앱에서 다른 탐구로 이동해도 유지한다.
- 채집 장소, 관찰 특징·근거, 주장, 예상과 결과 비교, 발견 제출은 사용자가 결정한다. 자동재생은 실험 준비·관찰에만 적용하며, 멈추면 원래 기록으로 복구한다. 설정 창이나 다른 화면으로 이동할 때 타이머를 정리한다.

대표 가로·세로·큰 글씨·연결 완료 스크린샷을 직접 열어 읽기와 배치를 확인했다. 브라우저 검사는 macOS의 헤드리스 Chrome에서 수행했다. 실제 학교 태블릿·Safari는 미실측이다. 공개 서버 배포는 하지 않았다. 로컬 미리보기는 [생명 코드 연구소](http://127.0.0.1:5187/)에서 확인할 수 있다.

## 주요 수정 파일

- `src/scenes/inquiry.ts`, `src/inquiry-controls.css`: 한 화면 배치, 단계별 조작, 보조 자료, 재생·속도 조작
- `src/inquiry-guidance.ts`, `src/inquiry-playback.ts`: 짧은 현재 행동 안내, 채집 장소를 대신 고르지 않는 자동재생
- `src/renderers/inquiry2d.ts`, `src/renderers/link-board.ts`: 관찰 확대, 속도 반영, 연결 보드 중복 제목 정리
- `tests/inquiry-screen-fit.mjs`, `tests/inquiry-playback.test.ts`: 화면·중간 상태 및 학습 결정 보호 회귀 검사
- 기존 학습 흐름·길잡이·재생·스테이지 검증 파일: 바뀐 조작 흐름에 맞춰 검사 갱신
- `docs/DESIGN_SYSTEM.md`: 스크롤 없는 현재 조작과 속도 선택 계약
