# 생명 코드 연구소 · 최종점검 · 2026-11-05

**최종 판정: 조건부 배포 가능.** 로컬 운영 빌드에서 다섯 연구소의 20개 탐구, 지도 복구, 보고서, 코어, 소개 카드, 저장 복원에 진행 차단이 재현되지 않았다. 실제 학교 기기·교실망, 교사 수업 검수, 기존 생성 자료의 납품 사용 조건 및 배포 후 점검은 남아 있다. 운영 사이트에는 이번 변경을 올리지 않았다.

기준 작업 트리: `feat/story-films-and-link-board`, 시작 커밋 `db13c3d`, 시작 시 변경 없음. USB 외장 SSD인 T7 Shield에서 작업과 빌드·브라우저 임시 데이터를 관리했다. 점검과 수정에는 `edu-design`, `game-final-check`, `edu-final-check`를 적용했다.
