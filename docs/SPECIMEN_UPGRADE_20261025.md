# 학습 표본 이미지와 활동 연결 개선 · 2026-10-25

## 확인한 문제와 수정

- 죽은 나무 자료에 버섯 확대 그림 또는 흙 그림이 표시되던 연결을 죽은 나무 전용 그림으로 교체했다.
- 빵과 낙엽에 원형 얼룩을 덧그리던 표현을 같은 원본 표본을 편집한 단계별 그림으로 바꿨다. 빵은 불규칙한 흰색·청록색 균사 질감, 낙엽은 조직의 손실과 남은 잎맥으로 변화를 보여 준다.
- 빵 반죽, 부푼 반죽, 곰팡이가 핀 식빵을 구분했다. 반죽의 전후 그림은 같은 그릇과 카메라 구도를 사용한다.
- 과일 변질 사례에는 변질된 사과 그림을 연결했다.
- 카드, 확대 자료, 관찰 시점, 전후 비교, 발견 도감, 소개 카드 저장이 공통 이미지 연결 규칙을 사용한다.
- 자료 확대 창의 그림을 키우고, 화면 크기와 관계없이 원본 비율을 유지한다. 관찰 사진과 비교 화면도 같은 비율을 유지한다.
- 짚신벌레 이동은 관찰 그림을 그대로 사용하며 정지·재생·기록에서 동일한 위치 계산을 사용한다.

## 단계별 연결

| 단계 | 이미지가 이어지는 방식 |
|---|---|
| 균류 관찰 M1 | 죽은 나무·곰팡이 빵의 발견 장소 → 버섯 주름·곰팡이 구조 확대 → 같은 단서로 새 표본 분류 |
| 연못 관찰 M2 | 연못 채집 → 해캄·짚신벌레 관찰 → 같은 짚신벌레의 두 위치 비교 → 발견 도감 |
| 세균 자료 조사 M3 | 기존 둥근·막대 모양 세균 그림과 자료 분류 유지 |
| 생활 속 사건 M4 | 같은 식빵·낙엽의 관찰 1~4 → 전후 비교와 표시 → 효모 이용·과일 변질 등 새 사례 적용 |
| 생명과학 설계 M5 | 재료 → 생물의 작용 → 결과의 구분 → 선택한 사례에 맞는 소개 카드와 저장 이미지 |

## 생성 자료

새 그림 10개: 죽은 나무 1, 변질된 과일 1, 반죽 전후 2, 식빵 변화 3, 낙엽 변화 3. 식빵·낙엽의 최초 모습은 기존 원본을 유지했다.

- 최적화 파일: `public/assets/specimen-*.webp`
- 이번 생성 PNG 원본: `assets/generated/specimens-20261025/`
- 전체 생성 프롬프트·파일별 크기: `assets/generated/specimens-20261025.json`

이 자료는 생성한 학습용 관찰 모형이며 실제 실험 사진·측정 원자료가 아니다. 관찰 번호는 비교 순서이고 특정 날짜·소요 시간·정량적 부피를 뜻하지 않는다. 기존 이미지와 학습 기록은 삭제하지 않았다.

## 검증

- 이미지 의미·단계 연결 회귀 검증을 포함한 단위 테스트 73개 통과.
- 20개 활동 전체 진행, 최종 보고서·코어 복구·PNG 저장·새로고침·학생/시연 기록 분리 검증 통과.
- 발견 도감의 관찰 사진과 확대 사진, 세 가지 소개 카드 저장의 원본 기록 보호 검증 통과.
- TypeScript 검사와 배포 빌드 통과.

화면 크기별 점검 및 배포 확인 결과는 최종 작업 결과에 함께 기록한다.
