# 생명 코드 연구소 교사 검수표

2026-11-21 코드에서 그대로 뽑음(커밋 기준: `3bcdc70`)

- 작업 트리에 커밋 안 된 변경(`src/renderers/inquiry2d.ts`, `src/renderers/map.ts` 등)이 있지만 이벤트 정리 코드만 바뀌었고 화면 문장은 바뀌지 않았다.
- 문장은 코드에 적힌 그대로 옮겼다. 고치거나 다듬지 않았다. `${…}`로 이어 붙는 문장은 화면에 보이는 모습으로 합쳐 적고, 출처 칸에 어떻게 붙는지 적었다.
- 검수 칸: 문장이 맞으면 「맞음」, 고쳐야 하면 「고칠 것」에 표시하고 메모 칸에 고칠 내용을 적어 주세요.
- 메모 칸의 「확인 필요」는 문장을 뽑은 사람이 과학적으로 틀리거나 헷갈려 보인다고 적은 것이다. 나머지 메모 칸은 비워 두었다.

## 2. 이 검수표를 읽는 법

- 활동별 「학습 목표」 문장은 코드에 따로 없다. 연구소(M1~M5)마다 있는 `stageObjectives` 문장을 각 연구소 머리 표에 적었다. 이 문장은 지금 화면 어디에도 나오지 않는다(코드에서 쓰는 곳을 찾지 못함).
- `curriculum.ts`의 `instruction`(활동 안내)과 `mentor`(토토 안내) 문장도 지금 화면 코드에서 쓰는 곳을 찾지 못했다. 활동 설계 문장이라 함께 실었고, 출처 칸에 「화면 노출 못 찾음」이라고 적었다.
- 「발견 기록」(`success`)은 활동을 마치면 뜨는 발견 카드, 연구 기록, 최종 보고서에 나온다.
- 과학 낱말 뜻(낱말 칩)은 활동마다 반복하지 않고 7장에 한 번만 적었다.
