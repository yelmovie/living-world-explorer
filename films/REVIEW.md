# 개념 영상 M1~M5 · 검토 기록 (2026-11-09)

「모아의 연구 노트」 5편, 각 18초, 1920×1080 30fps로 렌더 → 앱용 960×540 H.264+AAC. 무인 야간 작업이라 줄거리 세 가지를 따로 고르지 않고, 공통 지침의 A안 형식(질문 → 방금 한 탐구 재현 → 바뀐 곳 확대 + 이름표 → 결론 한 줄 → 캐릭터 반응)을 이 게임의 캐릭터(모아·토토)와 연구소 색으로 옮겼다.

## 만든 것과 결정

| 장면 | 시간 | 내용 |
|---|---|---|
| 질문 | 0–3.6 s | 모아가 걸어 들어와 말풍선으로 질문. 종이 넘김 효과음 |
| 탐구 재현 | 3.6–9.6 s | 카드 두 장이 시간차로 들어오고, 돋보기 고리(M1~M3) / "며칠 뒤"(M4) / "생물의 작용"(M5) 표시 뒤 원형으로 "후" 그림이 드러남. 결과 이름표는 카드 아래 지시선과 함께 |
| 확대 | 9.6–13.4 s | 바뀐 곳 한 장을 크게, 이름표는 가리키는 부분에 점(호박색)과 지시선으로 하나씩 |
| 결론 | 13.4–18 s | 결론 한 줄(핵심 낱말만 연구소 색 + 호박색 밑줄), 두 결과 카드를 근거로 아래에 두고 토토가 튀어 올라 반응 |

- 그림은 전부 `public/assets`의 게임 그림(모아·토토 전신, 표본 그림)을 그대로 썼다. 새 이미지 생성 없음. 효과음은 프로젝트의 Kenney CC0(`page-turn`, `capture`, `snap`, `success`, `hint`), 음악 없음.
- 문장 전체는 영상 아래 자막(`src/concept-captions.json` → 화면 자막·VTT·manifest)이 맡고, 영상 안에는 말풍선·이름표·결론 한 줄만 둔다.
- 마지막 프레임 = 포스터(`M*.webp`). 움직임 줄이기 설정에서는 자동재생 없이 이 포스터와 결론 자막이 보인다.
- 과학 확인: 균사·포자(M1), 해캄·짚신벌레·섬모(M2), 공·막대·나선 모양과 여러 사는 곳(M3), 음식 변질과 낙엽 분해(M4), 유산균·효모(균류)(M5)는 `src/curriculum.ts`의 탐구 문장·성취기준 4과12-01~03 범위 안. 입자·분자 모형 없음. M3의 "흙 → 막대 모양, 이 → 공 모양"은 자료 예시이고 결론은 "모양도 사는 곳도 여러 가지"로 일반화하지 않게 썼다.

## 측정한 것 / 눈으로 본 것

- `hyperframes check --json`: 5편 모두 `ok: true`, 오류 0. 남긴 경고: `nested_structure_needs_subcomposition`(한 파일 안의 장면 묶음 — 편당 장면이 4개라 하위 컴포지션으로 나누지 않음), `duplicate_media_discovery_risk`(같은 그림을 다른 장면에서 다시 씀, 의도).
- 처음 검사에서 고친 것: 마지막 토토 말풍선이 1.93초만 보임(`line_unread`) → 0.65초 앞당김. 밑줄 `z-index:-1` 경고 → `isolation:isolate`. 효과음 길이 = 실제 파일 길이로.
- `snapshot --review`로 5편의 장면 시작·중간·결론 프레임을 직접 봤다. 고친 것: M1 "균사" 이름표가 가리키는 점을 덮음 → 이름표를 오른쪽으로 옮김. M2 짚신벌레 이동 때 그림 모서리가 카드 안에 드러남 → 1.2배 확대 + 회전 ±3°로 줄임. 결론 줄이 머리 표식과 붙어 보임 → 30px 내림. 토토가 결론 장면 시작에 귀만 보임 → 시작 위치를 화면 밖으로.
- 소리: `ffmpeg silencedetect`로 효과음이 행동 시각(0.78·5.24·6.39·7.24·8.39·10.54·11.29·13.54·15.39 s, M1)에 맞는지 쟀다. 실제로 귀로 들은 것은 아니다. 평균 −28.6 dB, 최대 −3.1 dB(M1).

## 가장 약한 장면 / 더 시간이 있으면

- M2 탐구 재현: 짚신벌레의 "두 순간"을 한 그림의 이동으로 보여 줘 섬모 움직임 자체는 보이지 않는다. 다음엔 게임의 관찰 재생(`inquiry-playback`) 장면을 캡처해 실제 두 시점을 쓰는 편이 낫다.
- 카드 이름("우유", "빵 반죽")이 결과 그림으로 바뀐 뒤에도 재료 이름으로 남는다. 결과 이름표가 바로 아래에 있어 오해는 적지만, "우유 → 요구르트"처럼 바꾸는 편이 더 분명하다.
- 1280×720판(전자칠판용)은 만들지 않았다(기존 960×540 유지 원칙). 용량 여유는 충분하다.
